# TRAMA Acompanhamento

Ferramenta de planejamento científico do Grupo de Pesquisa TRAMA Pública.

## Estrutura
- `index.html` — aplicativo
- `assets/trama-publica.png` — logo do projeto
- `404.html` — redirecionamento simples para a página inicial

## Publicar no GitHub Pages
1. Envie `index.html`, `README.md`, `404.html`, `.gitignore` e a pasta `assets` para a raiz do repositório.
2. Vá em **Settings > Pages**.
3. Em **Source**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/root**.
5. Clique em **Save**.

Os dados ficam armazenados localmente no navegador de cada usuário.
